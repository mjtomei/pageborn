# Welcome to Pageborne

Add this file with Add files on your phone to try the local reader.

## Find your place

Use Contents, Search, the percentage slider, or the full Read from here pane. Tap a line to put it on the glasses.

## Reading modes

Pages advances a screen per swipe with adjustable overlap. Autoscroll advances one line at a time at 6–200 lines per minute; swipes adjust speed and a tap pauses or resumes.

## Your local library

Use Add files to save Markdown, text or PDF documents on this phone. Use Delete beside a document to remove the reader’s copy. The original file is unchanged.

Choose document in the glasses menu switches between saved files. Each file remembers your place.
